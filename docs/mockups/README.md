# Mockups (snapshot)

Source of the design canvas: https://claude.ai/artifact/416MBBuqTKwgNxzm4zJ7PW (private; share from its Share menu).

- Each `*.dc.html` is one screen or flow diagram, written in the canvas's Design Component format (plain HTML + inline styles). They reference the canvas runtime (`support.js`), so open them on the canvas to view; read them here for exact layout, copy, colors and sizes.
- `canvas.json` is the canvas index: board positions, titles, pages (Directions, All screens, Flows).
- The canvas is the live version; this folder is a snapshot. Re-copy after design changes.
- Design rules and tokens: [../05-ui-design-system.md](../05-ui-design-system.md).
